# PHP Contact Form - 5 Minute Checklist

Print this and check off each box! Super simple.

---

## ☐ Step 1: Configure (1 min)

- [ ] Open `contact.php` in code editor
- [ ] Line 27: Check email is `hello@bitglow.tech`
- [ ] Save file

---

## ☐ Step 2: Upload (2 min)

- [ ] Log in to Hostinger hPanel
- [ ] Files → File Manager
- [ ] Navigate to `public_html`
- [ ] Upload `contact.php`
- [ ] Upload `script.js` (if not already there)
- [ ] Upload `index.html` (if not already there)

**Files should be in same folder!**

---

## ☐ Step 3: Email Account (1 min)

- [ ] hPanel → Emails → Email Accounts
- [ ] Check if `hello@bitglow.tech` exists
- [ ] If NO: Click Create → Email: `hello` → Make password → Create

---

## ☐ Step 4: Test (1 min)

- [ ] Go to https://bitglow.tech
- [ ] Fill out contact form
- [ ] Use YOUR email address in the form
- [ ] Click SEND MESSAGE
- [ ] See green success message?

---

## ☐ Step 5: Verify (1 min)

- [ ] Check YOUR email for auto-reply
- [ ] hPanel → Emails → Webmail
- [ ] Log in as hello@bitglow.tech
- [ ] See the submission email?

---

## ✅ DONE!

**Your contact form is LIVE!** 🎉

---

## If Something's Wrong:

**No success message?**
- [ ] Check browser console (F12) for errors
- [ ] Make sure contact.php is uploaded

**No email received?**
- [ ] Check spam folder
- [ ] Verify hello@bitglow.tech exists
- [ ] Try submitting again

**404 error?**
- [ ] Check contact.php is in public_html
- [ ] Check filename is exactly `contact.php`

---
